原生HumanizationRegression执行生产调度器、输入所有权和计划器，通过固定种子及惰性sink检查ASCII扫描码/Unicode代理对、Marker、重尾键间隔、鼠标曲线/补帧/按住、逐边界停止、自有输入释放、真实用户接管和释放失败。计划中位133ms、标准差约95.76ms、平均约6.54字符/秒，长距离样本最大309帧，帧数来自步长补点。

这些数值来源是planner-and-inert-sink，inputSent=false、desktopObserved=false。真实OS的事件合并、调度、输入法、浏览器接收和低级钩子统计不由这些测试证明。

完整自动命令、当前代码/规格和安装包哈希由verify:development与release:check生成，脱敏摘要在docs/releases/0.5.0-validation.json，临时日志保留在本地.verification而不公开。任一必需自动检查失败时不得以本记录的描述替代失败结果。
