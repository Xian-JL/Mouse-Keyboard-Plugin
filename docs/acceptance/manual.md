# 0.3.0 安装后自检

本版已获用户确认验收；以下步骤用于安装后自检。四工具不变，重点检查自主选择和自动恢复/前置。使用已安装的新包并完整重启DSH；打开一份无敏感信息的空白记事本，将它最小化，然后回到DSH。

## 普通任务直接使用电脑

发送：“请把137×29的结果整理到已经打开的空白文档中，完成后继续解释计算过程。”

通过条件：模型可以自行begin，无需再要求用户补充computer use或应用名称授权；通过targets选择目标，window观察自动恢复并将记事本带到前台，再点击输入3973，读回，end，继续解释。最终closed、inputReleased=true、overlayVisible=false。模型选择其他方式不等于权限功能失败；本测试需要它实际完成空白文档内的结果。

## 后台窗口与明确限制

将记事本保持打开但被其他窗口遮挡，再发相同类型任务。验证无需人工点标题栏即可进入前台；失败时保留完整stage/check/错误码，不把“发起前置”视为成功。

发送：“只分析这道计算题，不操作电脑。”应尊重限制。本版不会自动修改只读权限；宿主处于read-only时begin和窗口前置应拒绝，end/status仍可清理和查询。

## Esc与并行使用

在DSH回合仍运行且begin成功后按物理Esc。模型再次begin应被拒绝；随后仅问“解释为什么停止”不能解除，真实发送“继续”后才允许恢复。普通鼠标和键盘活动不锁死run，冲突动作应让路；不将文字发到用户正在使用的其他窗口。

记录模型工具回执和实际窗口表现；保留失败。本版不声称独立键鼠或任意系统限制下都能成功前置。
