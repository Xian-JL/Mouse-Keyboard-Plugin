## 已知偏差

用户提供鼠标间隔中位约16ms、约61–64Hz、位移中位15–18px，未达旧110–130Hz和3–12px指标。按定稿提示词接受保留，不继续调参。源码已有高精度等待器和1ms请求，尚无同次数据把等待回退、调度与队列合并完全区分；不把Thread.Sleep粒度写成唯一已证实根因。特定课程平台采集政策不作为普遍保证。

MKP1=0x4D4B5031及OS注入属性保留，人工式通道不等于硬件来源。键速、指针目标和实际读回分开记录。
