## 2 真机验收（必须在真实桌面执行并留证）

### 2.1 输入交付（FR-01）

- [ ] **AC-INPUT-03** 记事本输入 `wc -l src/interrupt/Exception.cpp` 后立即 Enter
  - 判定：文本完整、无末尾字符丢失；回执 `verification=verified`
  - 证据：回执 JSON 片段 + 记事本内容截图
- [ ] **AC-INPUT-04** 画布连续输入三条 shell 命令，中间不人工 sleep
  - 判定：三条按序执行，无粘连、无 `>` 续行
  - 证据：终端输出截图

### 2.2 输入路径（FR-02）

- [ ] **AC-INPUT-07** 画布输入 `/bin/PageFaultTest 2`
  - 判定：大小写正确，命令被识别（不再出现 `not an exist command`）
  - 证据：终端截图 + 回执

### 2.3 安全边界（FR-03：恒开，无开关）

- [ ] **AC-INPUT-10** 恒开状态下向 DSH 自身窗口 / 安全桌面 / 密码框尝试输入
  - 判定：拒绝，错误码与 0.3.2 相同（`NOT_AUTHORIZED` / `PASSWORD_FIELD` 之一，记录实际值）
  - 证据：回执 + 前端提示截图

### 2.4 重试安全（FR-05）

- [ ] **AC-RCPT-08**（2026-11-07 用户修订）点「连接 GDB」**一次** → **等待 60 秒** → 再继续（期间不做任何操作）
  - 判定：没有第二次点击；60 秒后连接状态未被翻转；回执 `retryable=false`、`requiredAction=reobserve`
  - 证据：回执 + 60 秒前后的界面状态截图

### 2.5 观察等待（FR-06）

- [ ] **AC-WAIT-03**（2026-11-07 用户修订）触发一次 Build，**每 1 分钟截图一次**判断构建是否结束
  - 判定：看到 `All built.`（或提示符回到可输入态）即为结束；截图时间点要与真实构建时长一致
  - 说明：终端是 xterm，字符是像素、无障碍树读不到，因此**不再要求 `waitFor{kind:text}` 命中**；这条改为"1 分钟粒度的截图巡检"
  - 证据：每分钟一张的截图序列 + 各张时间戳
- [ ] **AC-WAIT-05**（2026-11-07 用户修订）画布执行命令后等待输出结束，**采样间隔固定 30 秒**
  - 判定：相邻两次采样（间隔 30 s）画面一致即 PASS；截图显示提示符已回到 `[/]#`
  - 说明：不用 150 ms 连续稳定——画布光标会闪，连续采样永远判"不稳定"；30 秒间隔正好跨过闪烁周期
  - 证据：回执 `durationMs` / `waitedMs` + 前后两张画布截图

### 2.6 区域证据（FR-09）

- [ ] **AC-REGION-01** 对 GDB 控制台取 `region`
  - 判定：落盘 PNG 尺寸等于 region，十六进制小字可读
  - 证据：PNG 文件 + 尺寸元数据
