# 0.5.0 发布记录

日期：2026-11-18。规格：1.10.0。基线：0.4.1。

本版根据用户提供的更新文档1.2开发，版本按直接请求定为0.5.0。默认开启自然输入节奏，保留四个工具和既有控制、观察、回执及拒绝边界。

## 输入与时序

新增humanizeEnabled与humanizeProfile设置，以及每次动作humanize=off/natural/slow。ASCII默认采用目标键盘布局的扫描码输入，非ASCII使用Unicode，显式unicode仍可用于兼容。保留原Marker和系统注入属性，不宣称这些输入来自真实硬件或不可被识别。

自然模式加入可取消的动作前等待、逐码点节奏和有限停顿、修饰键节奏、曲线路径、悬停及左键按住。元素内可小幅调整落点，图像坐标点保持精确；长距离按步长补帧，不强行限制整段路径为25帧。没有闲置微动、自动错字或滚轮。

长输入期间保留活动提示；工作线程关闭超时也尽力释放自有输入，并保留失败事实。分步发送后通过同一套OwnedInputs记录并释放自有输入，清理保留原扫描码/标志，避免留下Shift或左键按下状态。新按下前重验焦点/窗口，鼠标按下前重新核对实时元素边界和命中。用户活动、Esc及控制关闭可取消等待，部分发送不自动重放。

计划延迟上限20秒，输入执行有30秒内部期限，外层40秒预算保留。慢长文本超限在发送前拒绝，调用方需要分段或显式off。settledMs仍只表示交付后的额外稳定等待；humanization单独提供dwell、输入阶段耗时及计划元数据。

## 验证和范围

运行类型、构建、现有回归、Host生命周期、原生自检、调度/所有权故障注入、隐藏UIA、离屏绘制、旧版SDK及Node24下的0.2.2-rc.3 SDK及确切包检查。新原生回归用生产计划器和惰性输入sink，计划键间隔中位133ms、标准差约95.76ms、计划平均约6.54字符/秒；这不是操作系统低级钩子的实机采样结果。

本轮没有进行课程平台操作，没有采集改造前后真实键鼠探针，也没有以模型截图产出课程证据。更新文档提供的0.4.1历史样本保持其来源，未冒充本轮重新采集。物理Esc时延、实际鼠标事件数/按住时长、浏览器event.code和目标站点大小写仍需真机复验，未测项目为NOT_RUN。

## 安装

```powershell
dsh plugin --profile desktop add https://github.com/Xian-JL/Mouse-Keyboard-Plugin/releases/download/v0.5.0/mouse-keyboard-plugin-0.5.0.tgz
```

安装后需要完整重启DSH以替换已加载的Host及原生Helper。已有数值设置和显式false保留，新节奏缺省为natural；不自动绕过其他插件的宿主版本限制。
