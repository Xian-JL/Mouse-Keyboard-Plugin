# 0.3.1 发布记录

日期：2026-11-02。规格：1.6.0。基线：0.3.0。

本版按用户要求完成可靠性、观察效率和交付验证优化。保留四工具、已有键位及Windows x64范围，不新增应用启动、文件、剪贴板、右键、滚轮或拖拽。

## 变更

严重JSON错误回执关闭控制并保留发送事实；清理未知不冒报释放。修复畸形响应丢失pending请求，以及设置重挂载丢失任务和Esc状态。显式禁止电脑操作跨回合保留，由真实明确允许解除。

观察优先读取焦点，默认精简、按需展开；公开预览不修改私有验证证据。纯文本模型跳过PNG编码与传输，仍执行内部视觉保护。新增分阶段计时和超时分类，取消无限长度文本读取，扩展保守的多行证据来源。

结构化诊断记录实际回执错误和执行状态，不记录业务正文。公共CI与安装包检查可从新检出代码运行，不依赖作者本机验收文件或Desktop安装。

## 验证范围

自动检查覆盖故障回执、设置启停、持续禁用、Esc锁存、协议悬挂、观察预算、投影、隐藏Win32控件、离屏WPF及SDK工具管线。SDK固定0.2.1-rc.3和rc.5；本机安装的0.2.1-rc.5另执行真实Cordis/ToolRuntime和Helper无输入开关。

这些检查没有输入用户应用、激活业务窗口或截取用户桌面。物理Esc时限、混合DPI、浏览器/Electron实际编辑器和完整模型图片交付仍未在本轮真机操作中验证。0.3.0的人工确认不会作为本版新增行为的人工确认。

## 使用变化

默认compact返回有界预览；需要更多文字时用mk_observe window的detail=expanded。检查valueTruncated/valuePreview。已返回的后置观察可以用于下一步动作。

明确禁用后请发送“允许你操作电脑”才能重新允许；普通“继续”仅用于已有任务的恢复，不解除持续禁用。正常设置变更关闭run并使旧引用失效，任务上下文保留。
