# Mouse-Keyboard-Plugin 0.6.0

定稿版：能力冻结，后续只修缺陷。运行行为冻结于0.5.5；本版新增审计、验收与交付文档，不新增工具或输入通道。

输入通过SendInput提交；目标脚本/CDP/DOM执行、粘贴、helper网络输入及远程进程注入均未实现。布局请求和有界只读窗口消息单独列明。详细命令、字面误报复核和实机结果见[0.6.0验收记录](https://github.com/Xian-JL/Mouse-Keyboard-Plugin/blob/main/docs/acceptance/0.6.0.md)及[自动验证摘要](https://github.com/Xian-JL/Mouse-Keyboard-Plugin/blob/main/docs/releases/0.6.0-validation.json)。

本次按用户后续指示不再调用mk工具实机验收；新版本的实际输入、布局隔离和typos明确NOT_RUN。已完成的安装/重启与自动结果分别记录，未生成实机通过凭证。

## 已知偏差

用户独立钩子约61–64Hz、位移中位15–18px，未达旧性能目标，按本次冻结范围接受保留。MKP1与系统注入属性继续存在；“人工式”只描述操作通道、时序与轨迹目标，不代表真实硬件来源。完整历史矩阵未运行的场景保留NOT_RUN，不从指定冒烟推断全面通过。

## 安装

```powershell
dsh plugin --profile desktop add https://github.com/Xian-JL/Mouse-Keyboard-Plugin/releases/download/v0.6.0/mouse-keyboard-plugin-0.6.0.tgz
```

版本变化后完整重启DSH。既有配置、四工具、maxSpeed、±2px、Esc、文本校验和结束不恢复布局策略保持。
