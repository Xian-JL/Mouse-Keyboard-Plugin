# 0.5.5 发布记录

日期：2026-11-18。规格：1.13.0。基线：0.5.4。

## 布局门禁误拒绝

根据更新文档11.10，用户报告焦点HKL已达0x04090409但仍switch-timeout/english-required，导致Edge/ChatGPT不能观察。源码原本允许NativeMode=null，因此未把“null是唯一根因”写成已证实结论；本版移除主窗口线程布局必须相同的硬门槛，并分离HKL准备成功与辅助IME确认。

以实际焦点输入线程HKL为ready判据。无legacy IMM context时记录imeNative=false；转换查询失败仍为null。焦点已US但辅助证据不完整或冲突时，state=ready、verified=false且报告warning，允许观察和输入；真正非US仍拒绝。新增foregroundLayout及最多三种固定warnings，正文verification和最终值检查保持独立。

按授权进程实例和输入线程分别记录一次准备机会，解决多个目标共用整run单次状态的问题；新输入线程在观察时准备，已有US新线程可以只读登记。只向实际焦点窗口请求语言改变，取消对不同主窗口线程的附加请求，不向无关进程发消息。用户切回中文后不会对同一线程反复抢切。end仍不恢复；保留Esc、用户让路、部分输入不重放及既有输入节奏。

设计参考[Microsoft GetKeyboardLayout文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getkeyboardlayout)的线程布局查询语义及[ImmGetContext文档](https://learn.microsoft.com/en-us/windows/win32/api/imm/nf-imm-immgetcontext)的窗口IMM上下文查询与释放要求。不把legacy上下文缺失泛化为任意中文布局都可输入。

## 验证范围

新增LAYOUT-03，更新LAYOUT-01：覆盖US焦点/中文主线程、缺上下文、辅助IME查询未知和冲突、真正中文超时、独立目标线程、进程实例变化、无关模拟进程保持原状、取消、人工恢复、结束不恢复及有界警告透传。通过惰性sink运行生产输入计划核对mkTest 053, sample.的大小写、空格与半角标点；这不是对真实IME或实际应用发送文字。

完整自动检查、旧回归、SDK管线、原生编译和确切打包结果见0.5.5-validation.json。没有操控桌面，没有实际切换用户输入法，也未重新采集真实Edge/ChatGPT、微信线程或输入字段证据。上述用户要求的实机项目保留NOT_RUN，由manual.md逐条复验；不能将模拟结果或旧版本记录迁移为本版通过。

## 安装

```powershell
dsh plugin --profile desktop add https://github.com/Xian-JL/Mouse-Keyboard-Plugin/releases/download/v0.5.5/mouse-keyboard-plugin-0.5.5.tgz
```

完整退出并重启DSH后加载新Host和Helper，原配置保留，没有新增设置项。
