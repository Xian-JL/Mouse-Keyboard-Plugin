# 0.5.1 发布记录

日期：2026-11-18。规格：1.10.1。基线：0.5.0。

## 修改依据和实现

本版根据用户更新文档1.3及DSH提供的实机反馈开发。反馈记录0.5.0一次点击inputDurationMs=7281、210个移动事件，以及键间隔中位163ms、范围62—221ms。这些是用户提供的历史结果，不代表本轮重新测量或0.5.1已通过实机验收。

鼠标改用距离和有界对数正态速度安排600—1600ms运动预算（含悬停），常规路径约40—90个点。绝对截止时刻调度吸收校验/绘制开销，跳过过期中间点，限制追补突发；每点保留控制门、用户活动、安全桌面和前台检查，完整进程核验约100ms一次且点击前必做。落点±2px、精确图像坐标及最终像素/命中检查不变。移动过程指针绘制约32ms一次，并更新最终点。

等待使用作用域内的匿名高分辨率waitable timer，并在退出时关闭句柄；不修改全局计时精度，失败回退Sleep。实现依据[Microsoft CreateWaitableTimerExW文档](https://learn.microsoft.com/windows/win32/api/synchapi/nf-synchapi-createwaitabletimerexw)和[SetWaitableTimer文档](https://learn.microsoft.com/windows/win32/api/synchapi/nf-synchapi-setwaitabletimer)。系统调度仍会影响真实时序。

键盘默认使用对数正态短间隔、3—8字符簇、簇间停顿及低概率长停顿，另加入首字符、空格/标点后和大写前停顿。保持文本内容和快捷键语义，不自动打错/回删，不发送闲置微动，不加入滚轮或浏览器合帧能力。off/maxSpeed、控制开关、Esc、已有注入标记和拒绝边界保留。

新增humanization.mouseMoveDurationMs表示首次到末次成功MOVE提交的实际时差，与包含UIA/覆盖层/交付开销的inputDurationMs区分；并非应用接收时间或低级钩子结果。

## 验证和适用条件

固定种子与惰性sink的计划统计为按下间隔中位119ms、P95=680ms、P99=861ms、均摊4.86字符/秒，长距离样本最多89个运动点。回归覆盖上下文停顿、双尺度输入、移动截止调度和迟滞跳帧、每个移动/按键边界取消、自有输入释放、maxSpeed及预算拒绝。完整自动验证和打包校验记录见同目录validation.json。

更新文档的部分目标无法同时成立：任意长距离不可能既最多90点又保证每步≤8px；单一sigma=0.45的对数正态也不能产生所列尾部概率。本版明确采用有界事件数与混合停顿分布；310px代表样本验证位移中位3—8px，不对任意距离作此承诺。短路径、显示器间隙或运行时跳帧可以少于40个实际事件。

本轮不操控用户桌面，没有重新测量OS低级钩子、浏览器event.code/合帧、真实Esc时延或实际应用输入速度；0.5.1真实桌面验收仍为NOT_RUN，不能从计划器统计推断全矩阵通过。没有修改用户更新文档，也没有进行任何课程平台任务。

## 安装

```powershell
dsh plugin --profile desktop add https://github.com/Xian-JL/Mouse-Keyboard-Plugin/releases/download/v0.5.1/mouse-keyboard-plugin-0.5.1.tgz
```

升级保留已有配置。完整重启DSH后加载新Host和Helper；远程GitHub Release安装来源保留。
