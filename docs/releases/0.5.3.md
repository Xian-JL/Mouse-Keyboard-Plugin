# 0.5.3 发布记录

日期：2026-11-18。规格：1.11.0。基线：0.5.2。

## 根据更新文档11.8开发

DSH提供的0.5.2实测为移动1.118s、有效58Hz、位移中位16px；键盘中位156ms、P95=541ms、均摊4.1字符/秒。本版新增受控纠错、重复字符停顿和计时分辨率请求。源码原已包含高精度等待器和标点/空格/大写/首字符调制，因此未把“Sleep(8)是唯一根因”或“原来没有上下文”写成已证实结论。

新增typoRate百分数设置（默认1.5、范围0—5、支持小数并保留0）及type-only allowTypos（默认false）。只有显式opt-in、完整可读且选区有效的Notepad/wordpad普通文本、US布局和auto/scancode自然模式才可能启用；终端、命令、代码文件、浏览器及未知目标不会因flag被放开。每请求最多两处，明确计划相邻错字、等待、一个Backspace、等待、正确字符。回删前重新核对完整值和光标，变化则不删除；额外字母计入sentCodePoints，新增typos/typoEligible回执，最终仍验证原始请求。中断不保证自动恢复文字，不补发。

上下文保留现有调制并新增相邻同字符20—60ms。输入阶段成对调用timeBeginPeriod(1)/timeEndPeriod(1)，交付后及finally释放，maxSpeed不请求；保留高精度waitable timer，无忙等。新增timerResolutionMs、timerResolutionReleased、timerWaits诊断。实现遵循[Microsoft timeBeginPeriod文档](https://learn.microsoft.com/en-us/windows/win32/api/timeapi/nf-timeapi-timebeginperiod)及[timeEndPeriod文档](https://learn.microsoft.com/en-us/windows/win32/api/timeapi/nf-timeapi-timeendperiod)：成功请求需要匹配释放，现代Windows的实际行为受进程和可见性影响，不承诺全系统一律1ms或实际输入已达125Hz。

四工具、任务来源、Esc锁存、用户让路、注入标记、±2px落点及最终像素/命中边界保留。未加入闲置微动、滚轮、漂移、自动修改命令或隐藏注入能力。

## 验证范围

生产计划器/惰性sink覆盖80组固定种子5%压力样本（每次最多两处，包含77组发生纠错的计划）、最终插入值、额外码点计数、回删前内容/光标变化拒绝、逐步取消及US/Unicode/maxSpeed限制；这些不是真实键盘输入。标点分组计划P50比普通组高88ms；无重复ASCII基线仍为中位119ms、P95=680ms、均摊4.86字符/秒。鼠标2000px参考计划仍为200点、125.63Hz和位移中位10.05px。

新增HUM-08/09/10自动门禁、设置小数与显式0、原生计时资源正常/取消/失败/重复释放路径，以及无输入8ms等待/CPU探针。精确计时观测随运行负载变化，见0.5.3-validation.json内inertTimerProbe；不把惰性等待的CPU或间隔当作完整桌面输入结果。

本轮未操控用户桌面，未重新采集0.5.3的真实鼠标钩子、纠错应用读回、物理Esc时延或完整动作CPU。HUM-07及其他真实未测场景保留NOT_RUN，不把用户0.5.2记录迁移成0.5.3通过。用户更新文档原件和历史验收未改写。

## 安装

```powershell
dsh plugin --profile desktop add https://github.com/Xian-JL/Mouse-Keyboard-Plugin/releases/download/v0.5.3/mouse-keyboard-plugin-0.5.3.tgz
```

完整退出并重启DSH后加载新Host、Client和Helper。旧数值配置及显式false保留，typoRate缺省补1.5但仍需每次工具显式opt-in。
