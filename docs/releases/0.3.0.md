# 0.3.0 发布记录

日期：2026-10-30。规格：1.5.1。

用户已确认当前插件验收正确，并明确授权以 0.3.0 发布到其 GitHub 仓库。本次功能沿用已验收的 0.2.0-dev.1，运行源码仅更新版本常量，没有加入新的操作能力。

## 功能

四个工具完成开启、发现/前置观察、左键点击、文本/按键输入和正常交还。模型可为普通用户任务自行选择电脑操作，无需桌面关键词或逐窗口授权。已有最小化窗口可恢复并前置，物理 Esc 强制停止，普通用户活动使冲突动作让路。

保留蓝色实心无描边指针、DeepSeek 动画提示、真实焦点与目标身份检查、只读模式限制、密码控件拒绝及单次快照。无图片输入的模型使用 UIA 元素证据，禁用猜测坐标点击。

## 验证依据

发布前重新执行类型检查、构建、自动测试、原生编译/回归、实际 DSH 管线、Helper 生命周期、隐藏 UIA、离屏绘制、安装包检查及解包加载。release:check 将当前 src/ 与 helper/ 对已验收基线逐文件比较，仅允许两个版本常量变化，并校验确切 tarball 哈希。

用户确认作为本次发布的人工验收依据。此前矩阵中没有独立测量的全部应用兼容、混合 DPI、物理停止时限等场景不倒填为 PASS；完整矩阵门槛与本次用户批准发布的依据分别保留。详细本机证据不进入公开仓库。

## 范围

Windows x64，DeepSeek Harness >=0.2.1-rc.3 且 <0.3.0。共享 Windows 焦点与输入流；用户持续操作、系统限制或目标无响应时可能让路/失败，不提供独立后台键鼠。插件不包含应用启动、浏览器 DOM、文件管理、剪贴板、滚轮、拖拽或右键。

GitHub 发布源码及预构建 tarball；没有发布到 npm。包内 private 保留以防误发 npm。
