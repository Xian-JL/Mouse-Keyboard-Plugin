# 0.5.2 发布记录

日期：2026-11-18。规格：1.10.2。基线：0.5.1。

## 根据DSH实测修订

更新文档11.7记录0.5.1的一次移动为1.586s、85个MOVE、约54Hz、位移中位18px；键盘中位178ms、P95=545ms、均摊4.3字符/秒。这是用户提供的上一版本结果，本版保留键盘行为，集中修复鼠标采样密度。

取消固定40—90个事件限制，采用8ms时间网格（名义125Hz），事件数随时间与距离变化。曲线先按累计弧长定位，再以轻微平滑速度包络采样，避免长路径挤在前80%的时间内。连续接近替代80—200ms零事件悬停。截止调度器允许正常1ms晚醒，不再因严格8ms间距过滤而隔帧跳过；仍跳过过期帧、防止突发追补，并保留Esc和用户接管检查。

310、1000、2000px参考集合目标为首末0.6—1.6s、有效110—130Hz、步长中位3—12px。短距离无法同时满足全部指标，不制造绕行凑数；极长路径优先密度并延长时间，仍受20秒计划预算限制。slow、显示器间隙和系统卡顿单独记录。

元素落点±2px、精确图像坐标、最终像素/命中校验、按钮保持60—120ms、动作前等待、键盘节奏、输入所有权与注入标记均保留。没有增加工具、设置、闲置动作、自动改字或滚轮。

## 验证边界

固定种子及惰性sink测试覆盖300组参考距离/种子组合、长路径密度、近零距离、迟滞跳帧、1ms唤醒抖动、逐点取消和maxSpeed。2000px参考样本为200点、计划有效125.63Hz、位移中位10.05px。键盘计划统计仍为中位119ms、P95=680ms、P99=861ms、均摊4.86字符/秒；这些均是计划器结果。

自动验证和精确打包结果见同目录0.5.2-validation.json。没有操控用户桌面或重新采集0.5.2低级钩子数据，真实桌面验收保持NOT_RUN；用户提供的0.5.1结果不迁移为本版PASS。更新文档原件及历史验收文件未改写。

## 安装

```powershell
dsh plugin --profile desktop add https://github.com/Xian-JL/Mouse-Keyboard-Plugin/releases/download/v0.5.2/mouse-keyboard-plugin-0.5.2.tgz
```

完整退出并重启DSH后加载新Host及Helper；已有配置与远程安装来源保持。
